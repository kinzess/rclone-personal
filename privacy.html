rclone-personal 隐私政策

本说明适用于维护者本人在个人设备上运行的 rclone-personal，以及此应用说明网站。

1. 访问与使用的数据

在账号持有者授权后，rclone 按执行的操作访问 Google Drive 文件名称、目录结构、文件标识、时间等元数据，并在读取、下载、上传或导出文件时处理相应文件内容。读写权限也允许按用户操作重命名和删除文件。相关访问用于本人管理自己的云盘，不用于广告、出售数据或建立其他用户画像。

2. 本地存储、缓存与日志

Google OAuth 访问令牌、刷新令牌及客户端配置保存在运行 rclone 的设备上。文件内容可能依据 VFS 缓存设置保存到本地磁盘，包括尚待上传的内容。运行日志可能记录文件路径、执行操作及错误信息。维护者负责保护这些配置、缓存、日志及其备份。

本地缓存按照 rclone 配置管理，用户主动保存的本地副本由用户管理。撤销 Google 授权不会自动删除已有本地文件。清理待上传缓存前，应先确认上传完成。

3. 数据传输与第三方服务

Drive 数据通过 Google API 在本人设备与 Google 服务之间传输；配置网络代理时，请求会经过所配置的代理。本工具不主动向本站网页托管服务发送 Google Drive 文件内容或 OAuth 凭据，不向广告商出售 Google 用户数据。

本站使用 GitHub Pages 托管。页面不包含统计脚本、广告、登录表单或文件上传接口。GitHub 会为安全目的记录网站访问者的 IP 地址；相关处理适用 GitHub 自身的隐私政策。Google 及所使用代理服务的数据处理分别适用其相关政策与实际配置。

4. 权限控制与撤销

账号持有者可以停止本地 rclone 服务，并在 Google 账号的第三方应用访问设置中撤销相应授权。撤销后，继续访问 Drive 通常需要重新授权。维护者可以在确认数据已妥善保存后，自行删除本地配置、日志及副本。

5. 使用限制与联系

本应用仅供维护者本人使用。Google 用户数据的使用以本页披露的用途为限，并应遵守 Google API Services User Data Policy 及适用的 Limited Use 要求。运行方式或数据用途变化时，维护者应同步更新本说明。

如有问题，请使用 Google OAuth 授权界面中列出的用户支持邮箱联系维护者。
